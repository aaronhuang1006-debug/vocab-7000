學測七千單字查詢 — 網站檔案

index.html   網頁本身（搜尋、排版、詞表與級別）
L1.txt–L6.txt  各級單字內容（詞義、例句、相關字、字根），可直接用文字編輯器修改

注意：這些檔案要放在網頁主機上才能運作（GitHub Pages、Netlify、Cloudflare Pages 等皆可）。
直接在電腦上雙擊 index.html 會查不到詞義，因為瀏覽器禁止本機網頁讀取旁邊的文字檔。
本機預覽：在此資料夾開終端機執行  python3 -m http.server  再開 http://localhost:8000

修改內容：照原格式改 L?.txt 後重新上傳該檔即可。
